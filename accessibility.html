Accessibility

What this site does to stay usable, what we know is imperfect, and how to tell us when something does not work for you.

What the site does Known limitations Reporting a problem

A community that says anyone can join should have a website anyone can use. This page says what we have actually done, rather than claiming a standard we have not been audited against.

What the site does

  • Semantic HTML throughout, with one h1 per page and no skipped heading levels.
  • A skip link to jump straight past the navigation.
  • A visible focus outline on every link, button and field, so the keyboard position is never a guess.
  • The whole site is operable by keyboard. The mobile menu closes with Escape and returns focus to the button that opened it.
  • Form fields have real labels, and errors are announced with the field rather than only in a summary.
  • Errors are shown with a border, an icon and text — never by colour alone, which matters on a greyscale site more than most.
  • All movement is inside a prefers-reduced-motion guard, and stops entirely when that is set.
  • Images carry width and height so the page does not jump while it loads. Decorative images are hidden from screen readers.
  • Text reflows down to 320px without a horizontal scrollbar.
  • The structure diagram on the About page is replaced by a plain list on small screens, and carries a text description for screen readers.

What we know is imperfect

  • The site has not been audited by anyone outside the team, and none of us uses a screen reader daily. Testing by people who do would find things we have missed.
  • The display face is a book type with fine strokes. It is set large for that reason, but if you find it hard to read at your settings, tell us — that is fixable in one file.
  • There is no high-contrast variant. The palette is deliberately greyscale, and we have not yet checked every combination against the strictest contrast thresholds.
  • Some pages are long, and the contents lists in the margin are only there on wider screens.

Telling us something is wrong

Use the form and say what happened, what you were using, and what you expected. You do not need to know the technical cause. An accessibility problem is a bug, it gets treated as one, and we will tell you what we did about it.

If you would rather fix it yourself, the site is open source.
