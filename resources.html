Where to start

A short list of genuinely good starting points, and how the community shares the rest.

This is not a syllabus. It is a handful of places that are worth your first hour, chosen because they are free, well maintained, and unlikely to disappear.

How the community actually shares resources

Most of it happens in the study groups and the channels, where somebody recommends the thing that just worked for them. That is more useful than any fixed list, because it comes with a person you can ask about it. Treat the list below as a way in, not as the material.

Programming from the beginning

  • freeCodeCamp — free, structured, project-based, and enormous.
  • CS50x — Harvard's introduction to computer science. Hard, and worth it if you want the foundations rather than just the syntax.
  • The Odin Project — a full path into web development that expects you to build things.

Web and mobile

  • MDN Web Docs — the reference for HTML, CSS and JavaScript. Not a course; the thing you will have open every day.
  • roadmap.sh — useful for seeing what a field contains before you commit to a direction. Do not treat the roadmaps as checklists.

AI and data

  • Kaggle Learn — short, practical, and connected to datasets and competitions you can enter.
  • Microsoft Learn — solid free training, including cloud and AI paths that lead to certifications.

Design

  • Figma's resource library — design fundamentals written for people who are not designers yet.

Certifications

Cloud certifications in particular are far easier in a group than alone, because the syllabus is long and dull in exactly the way that a weekly commitment fixes. If you are working towards one, say so — there is a good chance somebody else is on the same path.

Something missing?

If you know a resource that belongs here, send it through the form or raise it at a meeting. This list should be short and stay short, so a good addition usually means something else comes off it.
