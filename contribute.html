Help build this site

This website is open source, has no build step, and is a reasonable first contribution if you have never worked on someone else's codebase.

Where it lives Running it How it is built What needs doing Proposing a change

The site you are reading is public, and members are welcome to work on it. For a lot of people it is a good first experience of changing code somebody else wrote.

Where it lives

github.com/devcom-goseong/community-web

Plain HTML, CSS and vanilla JavaScript. No framework, no bundler and no build step — you can open a page straight from disk and see your change.

Running it

Clone it, then open index.html. That is enough for anything except the contact form, which needs a small server function. For that:

  • npm install
  • npx netlify-cli dev

The README covers the rest, including what the environment variables do.

How it is put together

  • Every colour, size and spacing value is a custom property in css/variables.css. Change it there, not in the markup.
  • One typeface for the whole site. Hierarchy comes from size, weight and italic.
  • Greyscale only — no accent colour anywhere, including buttons and hover states.
  • JavaScript does two things: the mobile menu, and submitting the form. Every page works without it.

Things that need doing

  • The platform links in the footer are placeholders until the invite links exist.
  • The social sharing image is generated by a script using a substitute typeface. A proper export would be better.
  • Accessibility testing by somebody who actually uses a screen reader.
  • The rules are a working version and need the final wording confirmed.
  • Korean translations, if that turns out to be useful to members.

Proposing a change

Open an issue describing what you want to change before writing much of it, so nobody duplicates work. Small, focused changes are easier to review than large ones, and a change that only touches one thing can be accepted quickly.

Credit other people's work if you bring anything in from elsewhere. That is in the rules and it applies to the codebase too.
